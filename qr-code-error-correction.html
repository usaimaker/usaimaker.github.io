QR Code Error Correction Explained: L, M, Q and H

QR codes contain redundant data so a damaged or partly covered code can still be decoded. Four levels are defined: L recovers about 7%, M about 15%, Q about 25% and H about 30% of damaged codewords.

What to get right

Higher correction means more modules for the same payload, which makes the code denser and harder to scan at small sizes. Use H when you add a centre logo or expect scratches and abrasion; use M for a plain URL on a clean label where the code can stay small.

A checklist before you print

Balance three things together: payload length, error correction and physical print size. Shorten the URL first, then pick the lowest correction level that survives your real print conditions, then test the printed sample. Guessing at H for everything is a common cause of unscannable packaging.

FAQ

How small can a printed QR code be?

For a phone held about 30 cm away, 2 cm square is a practical minimum for short URLs. Larger codes are needed for long payloads such as vCards; always test the actual printed piece.

Do QR codes expire?

The code itself never expires. What expires is the destination: a link that is deleted, a PDF moved to a new path, or a short-link service that shuts down. Use a URL you control.
