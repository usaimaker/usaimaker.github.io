QR Code Design Best Practices for Print

QR codes fail in print far more often than on screen. The three variables that decide whether a code scans are contrast, size, and error correction — in that order, and all three are under your control before the file leaves the browser.

Keep dark modules on a light background. Inverted codes (light on dark) are decoded inconsistently by older phone cameras, and gradient fills or low-contrast brand colours are the number one cause of support tickets after a packaging run. A centre logo should stay under roughly 20% of the code area with error correction set to H.

What actually matters in practice

For digital use a PNG at 1024 px is plenty. For posters, labels and packaging, export SVG so the modules stay razor sharp at any physical size, and always include a quiet zone. Test the final artwork on at least two phones before sending it to the printer.

FAQ

Does a styled QR code still scan?

Yes, provided you keep strong contrast, a quiet zone around the code, and high error correction. Always test a printed sample with two different phones before a full print run.

Should I use a dynamic or a static QR code?

Use a static code when the destination will never change. If you may need to edit the destination later, print a code that points to a stable URL you control and redirect it, so the printed piece never has to be replaced.
